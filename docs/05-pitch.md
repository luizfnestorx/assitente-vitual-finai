# 🎙️ Pitch do Agente: FinAI

## 1. O Problema
Iniciantes em finanças pessoais enfrentam duas barreiras principais: **o excesso de jargões técnicos** que afasta o público leigo e a **falta de ferramentas confiáveis** para simular cenários reais. Além disso, a aplicação ingênua de IA Generativa no setor financeiro traz riscos sérios de **alucinações matemáticas** e vazamento de dados pessoais (PII)[cite: 2, 3].

## 2. A Solução (FinAI)
O **FinAI** é um assistente virtual educativo que alia a interface conversacional amigável dos modelos de linguagem à **execução determinística via código Python em sandbox**[cite: 3]. Ele permite que usuários entendam conceitos, organizem o orçamento doméstico e simulem rendimentos sem alucinações numéricas[cite: 3].

## 3. Principais Inovações e Segurança
- **Zero Alucinação Numérica:** A LLM atua na orquestração conversacional, enquanto a matemática financeira é calculada exclusivamente via código Python isolado[cite: 3].
- **Privacidade e LGPD:** Filtro de entrada automatizado que identifica e mascara dados sensíveis (ex: CPF) antes do processamento[cite: 2, 3].
- **Compliance e Guardrails:** Bloqueio rígido a recomendações diretas de investimentos e inclusão obrigatória de avisos legais (disclaimers) em todas as simulações[cite: 3].

## 4. Visão de Futuro
- Integração com APIs oficiais do Banco Central para atualização diária das taxas Selic, CDI e IPCA em tempo real[cite: 2].
- Expansão do motor de cálculo para amortizações imobiliárias (Tabela SAC e PRICE)[cite: 3].
